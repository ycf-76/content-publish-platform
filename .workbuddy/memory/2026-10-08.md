## 前端：流式匀速 + 思考光晕（已修）

大哥反馈两个体验问题：1) 流式输出「卡一下涌一大段」，没有 codex 那种匀速感；
2) 思考过程没有紫色光晕氛围。

**根因**：`useChatSSE.ts` 的 tick 用 `cps = backlog / targetLag` 纯比例追赶。
SSE 是 bursty 的（后端攒一批发一次），backlog 瞬间暴涨 → cps 一帧跳到 max → 吐一大段；
backlog 归零 → 停。再加上 `dt` 直接来自 rAF（后台/掉帧时抖），正反馈「卡几秒涌一段」。

**改法（4 个文件）**：
- `composables/useStreamSpeed.ts`：新增 `baseCps`（匀速基准，默认 900 字/秒）+ BOUNDS；
  `reset`/load/save/导出全链路接入。
- `composables/useChatSSE.ts`：tick 重写 ——
  ① 目标速率 = `baseCps` × `sqrt(backlog/soft)` 压缩（永不线性暴涨）；
  ② `cur.cps` 指数缓动跟随目标（tau=0.32s 惯性，单帧变化受限，绝不瞬间跳变）；
  ③ `dt` clamp 到 0.10s + 1/120s **固定步长累加器**消除 rAF 帧率抖动；
  ④ 收尾 `pendingSettle` 仍用 `backlog/lag` 快速追完但 clamp 上限。
- `views/SettingsView.vue`：新增「匀速基准速度」滑块（`baseCps`）。
- `composables/useAuraSmoke.ts`：正文锚点 `.dsh-aura-tail` 缺失时（思考阶段 content 为空），
  回退到 `.dsh-cell-reasoning-streaming .dsh-cell-header` 作为烟气发射源。
- `ChatView.vue` 全局块（不是 scoped）：`.dsh-cell-reasoning-streaming` 加紫色柔光边框 +
  `dsh-reasoning-aura-breath` 呼吸动画 + 图标/文字紫色化（亮暗两套）。
  ⚠️ 思考单元格类落在 AssistantMessageCell 内部节点，必须在 ChatView 全局 `<style>` 块写，
    scoped 的 chat-view.css 那份同名样式是死样式（参考 MEMORY 作用域坑）。

验证：`npx vue-tsc -b --noEmit` 通过。未做真机流观测，建议大哥跑一轮看匀速感与思考光晕。
