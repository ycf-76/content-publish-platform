# 结构陷阱清单

> AI 写作最常掉进去的句式结构。不是词的问题，是结构的问题。
> 原则：**看到这些结构就重构，不是微调。**

---

## 一、虚假对比（The Negation Pivot）

"不是X，是Y" 是 AI 最爱的句式。9/10 情况下直接说 Y 就够了。

| 模式 | 问题 |
|------|------|
| "The answer isn't X. It's Y." | 预设转折套路 |
| "It feels like X. It's actually Y." | setup/reveal 套路 |
| "The question isn't X. It's Y." | 修辞性误导 |
| "Not X. But Y." / "not X, it's Y" | 机械对比 |
| "stops being X and starts being Y" | 虚假转变弧 |
| "doesn't mean X, but actually Y" | 否定-断言拐杖 |
| "not just X but also Y" | 加性对冲 |

**改法**：直接说 Y。"The problem is Y." 不需要先否定 X。

## 二、否定列举（Negative Listing）

先列不是什么，再揭示是什么。修辞性脱衣舞。

| 模式 | 改法 |
|------|------|
| "Not a X... Not a Y... A Z." | 直接说 Z |
| "It wasn't X. It wasn't Y. It was Z." | 直接说 Z |

## 三、戏剧碎片化（Dramatic Fragmentation）

用碎片句制造强调，读起来像人造深刻。

| 模式 | 改法 |
|------|------|
| "[Noun]. That's it. That's the [thing]." | 完整句子 |
| "X. And Y. And Z." | 合并或用正常连接 |
| "This unlocks something. [Word]." | 完整陈述 |

## 四、修辞性设定（Rhetorical Setups）

宣布洞察而非交付洞察。

| 模式 | 改法 |
|------|------|
| "What if [reframe]?" | 直接说观点 |
| "Here's what I mean:" | 删，直接展示 |
| "Think about it:" | 删 |
| "And that's okay." | 删 |

## 五、被动语态

每个句子都需要主语在做事情。被动语态隐藏行动者、抽干能量。

| 模式 | 改法 |
|------|------|
| "X was created" | 谁创建的？ |
| "It is believed that" | 谁相信？ |
| "Mistakes were made" | 谁犯的？ |
| "The decision was reached" | 谁决定的？ |

## 六、节奏陷阱

| 模式 | 改法 |
|------|------|
| 三项列表 | 用两项或一项 |
| 问完立刻答 | 让问题呼吸或删掉 |
| 每段结尾都很劲 | 变化结尾 |
| 破折号堆砌 | 用逗号或句号替代 |
| "Not always. Not perfectly." | 对冲伪装安慰，删 |

## 七、中文特有结构陷阱

| 模式 | 问题 | 改法 |
|------|------|------|
| "首先…其次…最后…" | AI 三段论 | 拆成独立短句，不用序号连接 |
| "不仅…而且…更…" | 递进堆砌 | 只保留最强的那个 |
| "X的核心/本质/底层逻辑是Y" | 空洞断言 | 用具体例子证明 |
| "从X到Y" 空泛跨越 | 缺乏过程 | 直接描述变化结果 |
| "X意味着Y" | 过度解释 | 直接说 Y |
| 连续三个以上短句 | staccato | 长短交替 |
