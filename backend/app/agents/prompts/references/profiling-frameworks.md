# 受众画像框架详解

> 供 audience-profiler Skill 按需读取。SKILL.md 保留步骤骨架，具体框架模板在此。

---

## 一、受众画像框架

```
人口统计
  年龄段 / 性别 / 城市层级（一线~下沉）/ 人生阶段（学生/职场新人/宝妈/已婚已育）/ 收入水平

心理特征
  价值观（深层在意什么）/ 自我认同 / 向往 / 焦虑 / 影响源（KOL/朋友/家人/专家）

行为特征
  活跃平台 / 内容消费（图文/短视频/直播）/ 活跃时段
  消费习惯（冲动型/研究型/比价型/品牌忠诚）/ 互动方式（点赞/收藏/评论/转发/私信）

小红书特化行为
  收藏习惯（收藏=种草待办）/ 种草路径（搜→看→收藏→比价→下单）/ 笔记偏好（图文>视频 or 反之）
```

## 二、痛点与需求

### 痛点结构
```
痛点: [具体问题]
  严重度: [1-10] | 频率: [每天/每周/每月]
  当前解决方式 / 不解决的代价 / 情绪影响（焦虑/迷茫/自卑/烦躁）
  代表性声音: "[评论区/私信中的原话]"
```

**痛点分类**：技能型（不会做）、认知型（不知道）、资源型（找不到）、情感型（焦虑/不自信）、社交型（怕丢面子/跟不上潮流）。

### 需求
```
核心需求: [#1 期望] | 衡量指标: [怎么算满足] | 时间预期: [多久]
次要需求: [2-3 个补充需求]
终极期望: [一切顺利想达到什么]
JTBD: "当我 [场景]，我想要 [行动]，这样我就能 [结果]。"
```

## 三、内容偏好

```
内容类型偏好
  最爱看 / 容易收藏 / 容易评论 / 容易转发（分别是哪类内容）

格式偏好
  小红书: [图文卡片 > 图文笔记 > 视频笔记]
  抖音: [15秒 > 60秒 > 3分钟]
  B站: [5-10分钟 > 3分钟以下 > 10分钟以上]

触达方式
  发现路径（搜索/推荐/关注页/话题/热搜）/ 关键搜索词 / 竞品账号
```

## 五、评论区挖掘

从评论区和私信提取：
- 高频问题（≥3 次出现）
- 情绪信号（焦虑/兴奋/失望/好奇）
- 购买信号（"多少钱""在哪买""求链接"）
- 内容需求（"能出个XX教程吗""想看XX对比"）

## 六、画像卡模板

```
---
昵称: [虚构但典型]
简介: [1-2 句描述这个人]
---
需求/痛点:
  - [核心痛点]
  - [次要痛点]
平台/关注账号:
  - [常去的平台 + 关注的博主]
内容方向:
  - [爱看什么类型的内容]
心声:
  - "[一句代表TA内心想法的原话]"
JTBD:
  - "当我 [场景]，我想要 [行动]，这样我就能 [结果]。"
```

生成 2-4 张画像卡，覆盖核心受众的不同细分。

---

## 七、验证清单

- [ ] 画像基于真实数据（评论区/搜索/后台），不是凭空想象
- [ ] 足点足够具体（不是"想要更好的生活"这种空话）
- [ ] JTBD 包含场景+行动+结果，可指导选题
- [ ] 画像卡之间有差异（不是同一人的微调版）
- [ ] 内容偏好可指导格式选择（不是"什么都看"）

更新时机：每 30 天或粉丝量级变化时重新校准。
