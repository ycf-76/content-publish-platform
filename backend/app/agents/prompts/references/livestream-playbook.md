# 直播话术与流程手册

> livestream 的领域知识库：各场景话术结构、流程架构、互动形式库。

## 一、流程架构（波浪式结构）

- **开场暖场（5-10 分钟）**：聚集人气，不急于进主题
- **主体内容（占总时长 70%）**：按环节划分，每 15-20 分钟一个高潮点
- **穿插互动（每 20-30 分钟）**：抽奖、问答、连麦等留住观众
- **收尾引导（10-15 分钟）**：总结、预告、引导关注和转化

**带货直播商品上架顺序**：引流款（前期聚人气）→ 利润款（中期主推）→ 爆款/福利款（穿插留人）→ 压轴款（收尾冲刺）。

各类型核心目标：带货看 GMV/客单价/转化率；知识看粉丝增长/互动率/付费转化；娱乐看在线人数/互动量/打赏；品牌看曝光量/品牌搜索量/话题热度。

## 二、开场白设计

前 30 秒决定观众是否留下，必须包含：
1. 打招呼 + 自我介绍（简短有记忆点）
2. 本场亮点预告（给留下来的理由）
3. 互动指令（点赞/关注/评论区打字）

平台差异：抖音节奏快，5 秒内抓注意力；视频号可稍作铺垫；小红书直播偏种草分享。

## 三、主体话术结构

### 带货直播（每个商品）
痛点引入 → 产品展示（核心卖点不超过 3 个）→ 信任背书 → 价格锚定 → 催单话术 → 售后保障

### 知识分享（每个知识点）
问题引入 → 知识讲解（核心观点 + 案例）→ 互动确认 → 延伸引导

### 娱乐直播
话题引导 → 弹幕互动 → 才艺/游戏环节 → 情感连接

## 四、互动形式库

- 抽奖（关注 + 评论区打关键词）
- 问答（弹幕提问，主播解答）
- 投票（二选一）
- 连麦（邀请观众分享）
- 限时秒杀（限时限量，倒计时）

## 五、节奏与过渡

标注三类提示：
- **节奏**：哪里要快、哪里要慢、哪里要停顿
- **情绪**：兴奋、真诚、紧迫、感动
- **动作**：展示商品、看镜头、看弹幕

## 六、收尾与引导关注

本场总结 → 下期预告 → 引导关注 → 感谢话术。带货直播额外安排最后一波福利冲刺。

## 七、应急预案

- **冷场**：准备 5 个"万能话题"和互动游戏
- **负面评论**：忽略/幽默化解/正面回应/禁言
- **技术故障**：断流、没声音、画面卡顿的话术模板
- **翻车**：口误/争议言论的即时补救话术

## 八、开播前准备清单

- 设备：灯光、麦克风、网络、备用设备
- 内容：话术打印、商品排列、道具就位
- 平台：直播封面、标题、预告、商品链接
- 团队：主播、助播、场控、客服分工
- 状态：嗓子、形象、心态

## 九、小红书直播特化

- 小红书直播偏"种草分享"而非"硬卖"，话术要软
- 直播笔记可回放，话术设计要考虑"非实时观众"体验
- 合规：小红书直播禁止站外导流、禁止虚假宣传、禁止刷单
- 互动：小红书直播间点赞/评论/分享权重高于打赏
