# KOL 定价与 KPI 预估参考手册

> 供 collab-proposal 的报价计算和 KPI 预估提供数据基准。
> 所有数字基于 2024-2025 年国内主流社媒平台的行业中位数，仅作参考区间。

## 1. KOL 层级定义

| 层级 | 粉丝量 | 典型特征 |
|------|--------|----------|
| 素人 | <1 万 | 真实用户身份，内容朴素，适合铺量种草 |
| KOC | 1-10 万 | 有一定内容能力，垂类小圈子影响力，性价比高 |
| 腰部 KOL | 10-50 万 | 稳定产出，粉丝粘性强，品牌合作主力军 |
| 头部 KOL | 50-500 万 | 行业影响力显著，品牌背书效应强 |
| 顶流 | >500 万 | 跨圈层影响力，品牌大事件合作首选 |

## 3. 报价调整因子

| 调整因子 | 溢价幅度 | 触发条件 |
|----------|----------|----------|
| 垂直度溢价 | +20% 至 +50% | 账号深耕特定垂类 |
| 时效性/节日溢价 | +30% | 大促/节日期间 |
| 独家排他 | +50% | 合作期间不接竞品 |
| 二创授权 | +30% | 品牌方获得素材二次使用权 |
| 多平台分发 | +20% 至 +40% | 一条内容多平台同步发布 |
| 置顶/加精 | +10% 至 +20% | 内容在主页置顶 |

**计算公式**：调整后报价 = 基础报价 x (1 + 各项溢价之和)

## 4. CPE 校验

CPE（Cost Per Engagement）用于反向验证报价合理性。

| 平台 | CPE 合理区间 |
|------|-------------|
| 小红书 | 0.5-3 元 |
| 抖音 | 0.3-2 元 |
| B站 | 0.5-3 元 |

CPE = 报价 / 预估互动量。超出合理区间时标注警告。

## 5. KPI 预估公式

1. **预估曝光** = 粉丝数 x 平台曝光系数 x 内容类型系数
2. **预估互动** = 预估曝光 x 平台互动率基线
3. **预估转化** = 预估互动 x 内容转化率（无转化链路不强估）

| 平台 | 曝光系数 | 互动率基线 |
|------|---------|-----------|
| 小红书 | 0.3-0.5 | 3%-8% |
| 抖音 | 0.5-1.0 | 2%-5% |
| B站 | 0.2-0.4 | 3%-6% |

## 6. 小红书特化

- 蒲公英平台报价通常高于私下合作 20-30%（平台抽成+保障）
- 种草笔记报价高于普通笔记 15-20%（需声明合作，流量受限）
- 合集/清单类报价可上浮 10%（多品牌曝光，性价比高）
