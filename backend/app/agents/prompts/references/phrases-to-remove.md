# 英文 AI 味短语清除清单

> text-polisher 英文润色时使用。中文文案中夹杂英文时也适用。
> 原则：每个短语都无信息增量，删掉不损失任何含义。

---

## 清嗓开场（Throat-Clearing）

删掉这些开场白，直接说内容：

- "Here's the thing:"
- "Here's what/this/that [X]"
- "Here's why [X]"
- "The uncomfortable truth is"
- "It turns out"
- "The real [X] is"
- "Let me be clear"
- "The truth is,"
- "I'll say it again:"
- "I'm going to be honest"
- "Can we talk about"
- "Here's what I find interesting"

## 强调拐杖（Emphasis Crutches）

无意义的强调，直接删：

- "Full stop." / "Period."
- "Let that sink in."
- "This matters because"
- "Make no mistake"
- "Here's why that matters"

## 商务黑话（Business Jargon）

| 避免 | 用这个 |
|------|--------|
| Navigate (challenges) | Handle, address |
| Unpack (analysis) | Explain, examine |
| Lean into | Accept, embrace |
| Landscape (context) | Situation, field |
| Game-changer | Significant, important |
| Double down | Commit, increase |
| Deep dive | Analysis, examination |
| Take a step back | Reconsider |
| Moving forward | Next, from now |
| Circle back | Return to, revisit |
| On the same page | Aligned, agreed |

## 副词杀手

所有 -ly 副词都该被审查。这些是重犯：

- really / just / literally / genuinely / honestly / simply / actually
- deeply / truly / fundamentally / inherently / inevitably
- interestingly / importantly / crucially

以及这些填充短语：

- "At its core" / "In today's [X]" / "It's worth noting"
- "At the end of the day" / "When it comes to" / "In a world where"
- "The reality is"

## 元评论（Meta-Commentary）

删掉自指旁白，文章应该推进，不该宣布自己的结构：

- "Hint:" / "Plot twist:" / "Spoiler:"
- "You already know this, but"
- "But that's another post"
- "X is a feature, not a bug"
- "Let me walk you through..."
- "In this section, we'll..."
- "As we'll see..."

## 虚假代理（False Agency）

给无生命物加人动词，AI 特别爱这样写因为它避免指名行动者：

| 模式 | 修正 |
|------|------|
| "a complaint becomes a fix" | "The team fixed it that week" |
| "a bet lives or dies" | "Someone kills the project or ships it" |
| "the decision emerges" | "Someone decides" |
| "the culture shifts" | "People change behavior" |
| "the data tells us" | "Someone reads it and concludes" |
| "the market rewards" | "Buyers pay for things" |
