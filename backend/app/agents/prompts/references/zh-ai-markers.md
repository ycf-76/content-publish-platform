# 中文 AI 味标记词库

> 文案润色和去 AI 味的唯一标记词源。text-polisher 和 quality-gate 共用。
> 原则：**不是所有大词都要杀**——在正确语境下"创新""突破"可以用，杀的是空泛堆砌。

---

## 一、学术腔标记

| 标记词 | 替换建议 |
|--------|---------|
| 值得注意的是 | 删，直接说结论 |
| 综上所述 | 删，或用"所以" |
| 不难发现 | 删，直接陈述 |
| 首先…其次…最后 | 拆成短句，不用序号连接 |
| 不仅…更… | 只保留"更"后面的 |
| 此外 | 删，或用"还有" |
| 这意味着 | 删，直接说结果 |
| 不可否认 | 删，直接说事实 |
| 从X的角度来看 | 删，直接说观点 |

## 二、AI 味标记

| 标记词 | 替换建议 |
|--------|---------|
| 持久的 | 具体说多久 |
| 格局 | 删或换"局面" |
| 至关重要 | "关键"或具体说为什么重要 |
| 充满活力 | 具体描述什么状态 |
| 令人叹为观止 | 具体说哪里好 |
| 开创性 | "第一个"或"之前没人" |
| 卓越 | 具体说强在哪 |
| 赋能 | "帮你做到" |
| 底层逻辑 | "根本原因"或"本质" |
| 深度赋能 | 删 |
| 革命性 | "完全不同"或具体说变化 |
| 生态系统 | 删或换"圈子"/"体系" |
| 全方位 | 具体说哪些方面 |
| 一站式 | 具体说包含什么 |

## 三、客套话标记

| 标记词 | 替换建议 |
|--------|---------|
| 希望对您有帮助 | 删 |
| 好问题！ | 删 |
| 您说得完全正确 | 删 |
| 未来充满无限可能 | 具体说可能怎样 |
| 让我们一起 | 删，直接说行动 |
| 期待与您 | 删 |

## 四、小红书特化 AI 味

小红书有自己的一套 AI 味，比通用规则更隐蔽：

| 标记词 | 替换建议 |
|--------|---------|
| 绝绝子 | 具体说哪里好 |
| 一整个 | 删，或换"完全" |
| 大无语 | 具体说无语在哪 |
| 谁懂啊（空泛用时） | 具体说什么让人懂 |
| 拿捏（空泛用时） | 具体说怎么做到的 |
| 闭眼入 | 具体说为什么值得买 |
| 氛围感拉满 | 具体说哪里有氛围 |

## 五、句式标记

| 句式 | 问题 | 改造 |
|------|------|------|
| "从X到Y" 空泛两段 | 缺乏具体过程 | 直接描述变化结果 |
| "X的核心是Y" | 过于抽象 | 具体说X的Y是什么 |
| "X不仅仅是Y，更是Z" | 堆砌递进 | 只说Z |
| "X的本质/底层逻辑是Y" | 空洞断言 | 用例子证明 |

## 六、活人感注入（替换方向）

去 AI 味只是去掉坏的，还要注入好的：

| 技巧 | 示例 |
|------|------|
| 写身体反应 | "手抖着点开" 优于 "很激动" |
| 论述中故意打断 | 插一句吐槽/反问 |
| 短句后跟长句变节奏 | "结果呢？折腾了三天才搞定，中间踩了两个坑。" |
| 口语化连接 | "但你想啊" / "结果呢" / "说白了" |
| 第一人称经历 | "我当时也纠结" 优于 "很多人会纠结" |
| 具体数字替代模糊 | "3天涨了2000粉" 优于 "涨粉很快" |
