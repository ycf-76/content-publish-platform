# 卡片配方库

> 小红书卡片设计的唯一配方源。card-design Skill 引用。
> 原则：**一张卡片只讲一个核心观点**——别把一句话塞进大空白。

---

## 封面卡（cover，必须）

**三段式**：顶部 kicker(分类/悬念) + 中央大标题(一句核心) + 底部一条信息栏(来源/作者) + 发丝线。

- **墨像**：白底、黑标题 w200、一个点缀色只用在标题里一个关键词或一条下划线。
- **杂志**：深纸底、衬线大字、极淡背景纹理。
- **最小密度线**：封面内容相对空间(标题当主角)，但**必须**有顶 kicker + 底信息栏 + 发丝标题+副标共三层，且底部信息栏压占 ~88% 处（不能让下半截空）。副标题 + 副标要占到总高 40-55%，底部信息栏确定，八间留一条细线或一个大序号/大字母充当视觉锚点，避免八段>15% 空白。

## 正文卡（content，最常用）

一张一个核心观点。**别只写一句话然后留大空白**——用下列承载方式之一：

### 配方 A：账本行 / 要点列表（高密度、信息密）

- 4-6 行，每行：**主行(标题 40-44px)** + **副行(说明 24-26px muted)** + 可选右侧数据(标签)。行间用发丝线划开。
- **最小密度线**：≥4 行带副行 + 一个收尾段（≥3 行有副行；宽裕紧凑行必留空白）。每行高 100-140px，4-6 行刚好铺满。

### 配方 B：流程 / 步骤（流程类）

- 竖向 N 步，每步：序号(mono) + 标题(42px) + 描述(26px)，步距 28px，步间可加连接线。
- **最小密度线**：≥4 步（4 步每步≈96px + 头部）≈填满 1440。

### 配方 C：对比表 / 双栏（A vs B）

- 左右两栏对照，顶部各一个副标题，逐行对比项。适合优缺/前后/我们vs别人。
- **最小密度线**：≥5 个对比行，两栏等宽，行高一致。

### 配方 D：网格 / Bento 格（并置多个点）

- 网格卡，3:4 画幅 **3×2 = 6 格是甜点**，最多 8 格(4×2)。每格：一个小标题 + 一句 + 可选大数字。
- **最小密度线**：6 格（留大空）。格子等大、间距一致(≈24px)、最多一格用 accent 底。

## 数据卡（data）

- 一个**巨型数字**（墨像 180-200px w200 / 杂志衬线）当主角 + 一句 kicker(这数字是什么) + 一句 context(对比基准/来源)。
- 多个数字 → 用网格格(配方 D)每格一个数。
- **最小密度线**：单数字卡必须有"kicker + 巨数 + 单位 + 一句解释 + 底部来源"五层，否则空。

## 金句 / 描述卡（quote，仅允许较空）

- 一句话金句(60-64px 斜体/大字) + 出处/作者(mono) + 一条发丝线。
- 允许 ≈40% 内容，但**必须补三锚点**：顶 kicker/日期 + 底出处处 + 一条细线。绝不整片空白。

## 收尾卡（CTA / summary）

- 回顾 3-5 个要点(小账本行) + 一句行动号(关注/收藏/评论) + 账号水印。
- **别只放一句"关注我"**——要点回顾填满。

## 品类 → 立场 → 配方速查

| 内容品类 | 立场 | 首面 | 正文配方 |
|---|---|---|---|
| 知识解析 / 科普 | 墨像(克莱因蓝) 或 杂志(Indigo Porcelain) | 首面 | 账本(要点) + 流程(方法) + 数据(结果) + 收尾(应用) |
| AI 工具 / 产品评测 | 墨像(克莱因蓝) | 首面 | 账本 + 对比行 + 数据 |
| 知识科普 / 评测清单 | 杂志(Ink/Dune) 或 墨像 | 首面 | 账本 + 流程 |
| 生活方式 / 阅读 / 情感 | 杂志(Kraft/Dune 暖纸) | 首面 | 金句 + 账本 |
| 数据报告 | 墨像 | 数据首面 | 数据 + 收尾 + 对比行 |

> 知识解析示例(如 SwanTale 那种)：**墨像 + 克莱因蓝**。封面 标题+一句话要点,填到底 → 知识速览(账本:要点/要点/方法/结果 4 行带副行) → 方法(流程 4-5 步,铺满) → 结果(1-2 个关键数+对比行) → 应用+总结(收尾 6 格 或 账本 + CTA)。每张 card_audit 必须 PASS。

## 最小密度线（所有卡片通用）

不管用什么配方，每张卡必须满足：

1. 内容覆盖 ≥85% 画幅（1080×1440）
2. 无理由的纯空白带 >15% 画幅（216px）即判失败
3. 底部必须有信息栏或来源行，不能大段留白
4. 如果内容确实少 → 换 1:1 画幅（1080×1080），别硬撑 3:4
