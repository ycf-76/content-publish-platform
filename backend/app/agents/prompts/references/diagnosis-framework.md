# 账号诊断框架

对着具体画像做诊断，不是通用打分。每一维都要落到"离该账号自己的定位有多远"。

## 一、垂直度

账号内容标签是否集中、能否被平台正确识别。

| 现状 | 判据 |
|------|------|
| 高 | 近10条内容题材集中在1-2个方向，标签一致 |
| 中 | 主线清晰但夹杂无关内容（>30%偏离定位） |
| 低 | 题材发散、平台难以打标，推荐不精准 |

证据来源：近期内容题材分布 vs identity里的"内容方向"。

## 二、定位清晰度

能否一句话说清"这个账号是干嘛的、对谁有用"。

- 清晰：主页简介+内容能让新用户3秒get到价值主张与差异化
- 模糊：定位泛（如"分享生活"）、无差异化、跟大号同质

证据：identity的"我是谁/差异化"+主页信息。

## 三、限流/降权信号自检

逐项排查：
- 近期播放/曝光断崖式下跌（对比历史均值）
- 内容含搬运/二次剪辑未二创
- 触发违禁/敏感词、极限词
- 营销过重（硬广、频繁挂链接/导流）
- 互动率异常低（曝光有但赞藏评极少）
- 短时间频繁发布/批量搬运特征
- 带违规外链、第三方平台引流

命中项越多，限流可能性越大。结论要说"疑似"，给自查方向。

## 四、流量池阶段判断

| 阶段 | 特征 | 核心任务 |
|------|------|----------|
| 0-500（冷启动） | 无稳定推荐 | 打磨垂直度、跑通基础内容、明确定位 |
| 500-5k（起量） | 偶有小爆 | 找到可复制的内容模型、稳定更新节奏、强化钩子 |
| 5k-1w（放大） | 有稳定推荐 | 批量复制爆款结构、做系列化、提升关注转化 |
| 1w+（沉淀） | 有粉丝基本盘 | 私域/变现、矩阵、粉丝深度运营 |

## 五、内容-受众匹配

内容是否打中audience里定义的人群与痛点。

- 高互动内容的题材/情绪 vs audience痛点是否吻合
- 错配信号：自认为的受众与实际互动人群不一致

## 处方原则

每个问题三段式：**病因→证据→处方**
- 病因：诊断出的具体问题
- 证据：用数据/内容佐证
- 处方：具体可执行动作，不写"多互动、坚持更新"这类正确的废话

## 小红书特化诊断项

在标准五维之外，小红书场景额外诊断：

| 诊断项 | 说明 |
|--------|------|
| 笔记类型分布 | 是否过度集中在一种笔记类型 |
| 收藏率 | 小红书核心指标，收藏率<5%需关注 |
| 种草力匹配 | 种草型账号却发太多拔草内容，定位矛盾 |
| 封面一致性 | 封面风格是否统一（影响主页转化） |
| 标签使用 | 是否充分利用小红书话题标签流量 |
