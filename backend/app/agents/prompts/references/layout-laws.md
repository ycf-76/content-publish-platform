# 布局法则：填满画面（消灭空白）

> 社交卡是一张张**单独满看**的，不像杂志翻开两页吸留白——**没填的卡直接被嫌 PPT 缺了个元素**。
> 这是小红书卡片最常见、最刺眼的廉价感来源。本文件是门禁。

## 总则

- **内容必须覆盖 ≥85% 画幅**（即 1080px / 1440px）。
- **任何无理由的纯空白带 >15% 画幅（216px）即判失败。**
- 渲染后必须跑 `card_audit.py`（见 SKILL.md 第 5 步）验证，全 PASS 才交。

## 4 层密度自检（渲染后，也是 card_audit 的判据）

把成品图切成 4 条各 360px 的带（-25% / 25-50% / 50-75% / 75-100%），逐带看是否有内容：

- **通过**：① 底部带(75-100%)有实质内容（不能纯空）；② 相邻两带不同时为空；③ 整体填充 ≥85%。
- **典型失败**（SwanTale 卡就是）：内容全在上 2 层，第 3-4 层纯空 → 头重脚轻 + 底部大片空白。

## 少内容怎么办（直接解决"底部留白"）

**绝不**做：
- 🚫 `<div style="flex:1"></div>` 把内容顶到垂直居中（下面留大片空白）——这是最常见的错误做法。
- 🚫 加装饰性 blob / 圆圈 / 水波 / 贴纸 / 无关插画"填空"（那是另一种廉价）。
- 🚫 无脑把大标题拉大（标题该多大有 typography 法则）。

**要做**（按填充优先级，从上到下试）：
1. **扩内容**：把要点写透——加一行"为什么"、加一个类比、加数据、加一条边际观察(marginalia)、把 3 条要点补到 4-5 条。知识卡永远有更多可讲的。
2. **加结构化承载**：账本行(带副行的列表)、流程、线框步骤、对比表、网格格——这些天然高密度且有信息量。
3. **换更密度或更宽内容的配方**（见 card-recipes 的最小密度线）。
4. **真内容就是少** → **换 1:1 画幅（1080×1080）**，别硬撑 3:4。
5. 若确定是"呼吸型"配方（金句/单句描述，允许≈40% 内容）→ **必须补三个锚点**：顶部 kicker/日期 + 底部来源/出处行(20px mono) + 其上一条发丝线，否则空白嫌"缺内容"而非"呼吸"。

## 纵向节奏（rhythm）

- 段尾各留 ~8% 间距（约 80-110px），作为有意的呼吸，不算空白。
- 大标题下间距 ≈18px、局部小标题中 ≈16px。
- **均匀分布内容块**：多个要点/卡片之间用相等的间距（用 8/12/16/24/32/40/48/64px 这套 token，别随意 px），让它们从上铺到下（`justify-content: space-between` 或 均匀 gap），而不是挤在顶部。
- 每种结构的深度预算参考：账本每行 100-140px；流程每步(标题42+描述26+间距28)≈96px + 头部)≈填满 1440；网格 3×2 每格约 380px。据此让内容恰好铺满 1440。

## 溢出修正策略（反向：内容太多或溢出）

- 超 1-40px → 上移/收一处间距；40-90px → 压局部间距 + 缩一区块；90-160px → 略缩标题/压一段落；160px+ → 换更宽内容配方或有删减内容。
- 改完再查底部空白到反向（为了避免溢出又把内容顶上去留出尾部空白）。

## 网格

- 墨像系：严格 12 格。**左对齐**，非对称留白，标题靠左（**不是居中**）。
- 杂志系：单栏/双栏，衬线正文，用细线(1-2px)和账本行分隔，不靠卡片毛玻璃。
- 间距 token（全站只用这些值）：8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 px。
