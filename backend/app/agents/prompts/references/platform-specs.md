# 跨平台规格

> 各平台内容格式差异的唯一参考源。social-content 和 post-formatter Skill 共用。
> 原则：**同一内容，不同平台不是简单复制，而是适配语气/字数/格式/标签。**

---

## 小红书

| 元素 | 规格 |
|------|------|
| 图片 | 1080×1440（3:4 竖版）或 1080×1080（1:1），最多 18 张 |
| 正文 | ≤1000 全角字（含标点），首行决定 80% 打开率 |
| 标签 | 5-10 个，`#话题` 格式，放文末 |
| 发布时间 | 7-9 点、12-13 点、18-22 点 |

**内容规则**：
- 封面图 + 标题决定 90% 点击，正文只决定收藏
- 语气口语化、闺蜜感、真人分享，绝不用官方腔、绝不用 AI 味
- 多用 emoji 分点，每段 1-3 行，避免大段文字
- 结尾引导收藏/评论："码住""姐妹们冲""评论区告诉我"
- 违禁词会限流：避免绝对化用语、医疗功效、传销话术

## 抖音

| 元素 | 规格 |
|------|------|
| 视频 | 1080×1920（9:16 竖版），15-60s 为主 |
| 标题/文案 | ≤15 字可看，剪映前置 |
| 标签 | 3-5 个，含 1-2 个热点标签挑流量 |
| 音频 | 热门 BGM 提升推荐 |
| 发布时间 | 12-13 点、18-22 点 |

**内容规则**：
- 前 3 秒定生死，钩子必须在开头
- 完播率是核心指标，节奏快、每 3-5 秒有变化
- 字幕/大字报（大量静音观看）
- 结尾 CTA："关注不迷路""评论区告诉我""看到最后有彩蛋"
- 热点标签提升初始推荐

## B站

| 元素 | 规格 |
|------|------|
| 视频 | 1920×1080（16:9）为主，竖屏动态(小视频) |
| 标题 | ≤80 字，信息量足、带梗或悬念 |
| 封面 | 1146×717，三连击引导封面文案 |
| 分区标签 | 分区前 2 层关键，标签 4-10 个 |
| 时长 | 中视频 3-10 分钟留存最佳 |

**内容规则**：
- 受众年轻、爱梗、反感套路，深度内容与趣味并重
- 开头 15 秒交代"这期讲什么、为什么值得看"
- 引导"一键三连"（点赞/投币/收藏） 促进互动
- 标题适度标题党，标题与内容不符会反感

## 微博

| 元素 | 规格 |
|------|------|
| 正文 | 140 字（短内容最佳），可长文折叠 |
| 图片 | 单图 / 九宫格，配图强可传播 |
| 话题 | 1-3 个`#话题#`（双井号包裹），带话题广场流量 |
| 发布时间 | 早 8-9 点、午 12 点、晚 20-22 点 |

**内容规则**：
- 短平快，情绪化、观点化内容易转发
- #话题# 必须前置、话题主持人带流量
- @相关大V/官方 提升曝光（相关时）
- 引导转发+评论（转发抽奖品、转发领"福利"）

## 公众号

| 元素 | 规格 |
|------|------|
| 标题 | 图文标题≤64 字，前 22 字决定打开率 |
| 正文 | 1000-3000 字深度文，排版留白 |
| 封面 | 900×383（2.35:1）封面 |
| 排版 | 图文标题分段、重点加粗、留白 |

**内容规则**：
- 打开率看标题，前 3 段必须抓住读者
- 一次只讲一个核心观点，逻辑递进
- 结尾引导"在看/分享/关注"，可留悬念
- 外链引流，流量导公众号和小程序

## 知乎

| 元素 | 规格 |
|------|------|
| 回答/文章 | 800-3000 字，专业、有信息增量 |
| 开头 | 前 3 行给结论或反直觉观点 |
| 结尾 | 分点论述 + 案例 + 数据 |
| 标签 | 绑定相关"话题"（话题页流量） |

**内容规则**：
- 专业、理性、有干货，绝口水化和情绪化
- 开头先抛结论/反直觉观点，再展开论证
- 用数据、例子、亲身经历建立可信度
- 结尾引导"赞同+收藏"（赞同提升排序权重）

## 次要平台：出海平台

### X / Twitter

| 元素 | 规格 |
|------|------|
| 字数 | 280（免费）/ 25,000(Premium) |
| 标签 | 1-2 个，多了降互动 |
| 链接 | 降 reach，放第一条回复 |

- 线索决定一切，短句、多换行；提问动回复，引用转发优于纯转发。

### LinkedIn

| 元素 | 规格 |
|------|------|
| 字数 | 3,000（空格），约 210 字数后折叠 |
| 标签 | 3-5 个放末尾 |
| Carousel | PDF，1080×1080 或 1080×1350/页 |

- 前 2-3 行必须抓住前职业动作；个人故事 > 企业公告；外链放评论。
