# 文案框架库

> 本项目唯一框架定义源。各 Skill 引用同一份，避免漂移。
> 选一个框架 = 一条内容主线，把主题拆进各阶段按顺序写。**选定后只用一个，不混用。**

---

## 按内容目的选框架

| 你要做什么 | 选哪个 | 一句话逻辑 |
|-----------|--------|-----------|
| 读者有痛点，要转化 | **PAS** | 痛点→放大→方案，让人坐不住再给解法 |
| 从围观引到心动，做推广 | **AIDA** | 注意→兴趣→欲望→行动，完整转化链路 |
| 前后对比强烈，讲转变 | **BAB** | 现状→理想→桥梁，画面感最强 |
| 逐条提炼卖点 | **FAB** | 特性→优势→利益，证据链清晰 |
| 标题/首行自检 | **4U** | 有用/紧迫/独特/具体，四条尽量多占 |
| 有案例有数据，讲怎么做到的 | **STAR** | 情境→任务→行动→结果，复盘体 |
| 讲故事输出观点，求共鸣 | **SLAY** | 故事→道理→建议→交给你，互动体 |
| 教程/步骤型 | **STEP** | 目标→前提→分步→验证→注意，手把手 |

## PAS ｜ 痛点 → 放大 → 方案

- **P 痛点**：一句话点破读者正在经历的具体困扰，越具体代入感越强
- **A 放大**：不解决会怎样——成本、尴尬、持续困扰，让人坐不住
- **S 方案**：给出解法，落到可感知的结果
- 适用：带货、种草、卖服务、任何"读者有明确痛点"的场景
- 平台适配：小红书首行放痛点钩子；公众号痛点展开写透再给方案；短视频前3秒用痛点开场

## AIDA ｜ 注意 → 兴趣 → 欲望 → 行动

- **A 注意**：钩子抓眼球（痛点/反差/利益/提问）
- **I 兴趣**：放大相关性，"说的就是我"
- **D 欲望**：卖点 + 证据 + 场景，制造想要
- **A 行动**：明确 CTA + 行动理由（限时/赠品/价格锚点）
- 适用：信息流广告、落地页、新品发布、活动预热
- 平台适配：抖音/视频号前3秒必须完成Attention；小红书Interest和Desire合并为"亲测体验"

## BAB ｜ 现状 → 改变后 → 桥梁

- **B 现状**：用户当前的糟糕/停滞状态
- **A 改变后**：用了之后的理想状态
- **B 桥梁**：产品就是从现状到理想的那座桥
- 适用：前后对比强烈的转变类（减肥/学习/效率）、种草、转化
- 平台适配：小红书用"我也遇到过→直到我用了"叙事；知乎用数据对比更硬核

## FAB ｜ 特性 → 优势 → 利益

- **F 特性**：产品客观拥有什么（成分、参数、功能、材质）
- **A 优势**：这个特性带来什么好处（比别的强在哪）
- **B 利益**：对用户意味着什么（能解决什么、变成什么样）
- 写法：`因为{特性}，所以{优势}，这意味着你能{利益}`。主推利益，特性做证据
- 适用：卖点提炼、详情页分层、产品对比
- 平台适配：电商详情页逐条FAB；小红书揉进种草叙事不单独列

## 4U ｜ 有用 / 紧迫 / 独特 / 具体

- **Useful 有用** / **Urgent 紧迫** / **Unique 独特** / **Ultra-specific 具体**
- 用于标题和首行自检，四条尽量多占
- 适用：所有平台的首行/标题质量检查

## STAR ｜ 情境 → 任务 → 行动 → 结果

- **S 情境**：谁在什么处境
- **T 任务**：要解决的具体问题或目标
- **A 行动**：一步步做了什么（1. 2. 3.）
- **R 结果**：可量化的成果或转变
- 适用：案例复盘、经验分享、客户故事、方法论拆解
- 平台适配：公众号/知乎适合长版STAR；小红书压缩为"踩坑→做法→结果"三段

## SLAY ｜ 故事 → 道理 → 建议 → 你

- **S 故事**：一段真实、有画面的小故事开场
- **L 道理**：从故事里提炼观点
- **A 建议**：给读者可落地的具体做法
- **Y 交给你**：把话题抛回读者，引导互动
- 适用：个人向、干货带情绪、观点输出、求共鸣
- 平台适配：小红书/微博故事要短（3句内）；公众号/知乎故事可以展开

## STEP ｜ 目标 → 前提 → 分步 → 验证 → 注意

- **目标**：这教程能帮你达成什么
- **前提**：需要什么基础/工具/素材
- **分步**：每步写操作→预期结果→常见卡点
- **验证**：怎么确认做对了
- **注意**：容易踩的坑和替代方案
- 适用：教程、操作指南、配置步骤
- 平台适配：小红书分步配图每步一张；B站/抖音按步骤切分镜；知乎可以纯文字长版

## 去AI感规则（所有平台通用）

**禁用词**：
- 学术腔：说白了/值得注意的是/综上所述/不难发现/首先…其次…最后/不仅…更…/此外/这意味着/不可否认
- AI味：持久的/格局/至关重要/充满活力/令人叹为观止/开创性/卓越/赋能/底层逻辑/深度赋能
- 客套话：希望对您有帮助/好问题！/您说得完全正确/未来充满无限可能

**句式改造**：
- 拆长句（≤20字一断）
- 删过渡词堆叠（"然后接着其次"）
- 删空泛修饰（"标志着/彰显了/体现了"）
- 删三段式法则（"首先其次最后"）

**注入活人感**：
- 写身体反应不写情绪总结（"手抖着点开"优于"很激动"）
- 论述中故意打断（插一句吐槽/反问）
- 短句后跟长句变节奏
- 口语化连接（"但你想啊"/"结果呢"）

**平台特化**：
- 小红书：语气软、emoji点缀（不堆砌）、"姐妹/宝子"按画像调性
- 公众号：可长句、可文言点缀、结构更正式
- 知乎：反常识开头、数据支撑、逻辑链完整
- 抖音/视频号：口语化、短句为主、情绪起伏大
- 微博：观点前置、情绪先行、140字内抓完
