# 创作者声音画像公式

声音画像 = 跨样本提取四维信号 → 压缩为可执行的风格声明。供 voice-builder 和 profile-builder 的 style 维度使用。

## 四维信号提取框架

### 1. 声音信号

| 信号 | 怎么提取 | 示例 |
|------|---------|------|
| 平均句长 | 统计各样本句子字数，给范围和均值 | 15-25字，均值20字 |
| 段落节奏 | 单行换行 vs 空行分段、短促 vs 流畅 | 短句密集+emoji点缀 |
| 开头风格 | 分类：反常识/提问/数据/故事/自白/观察 | 5篇中3篇用提问开头 |
| 人称视角 | 第一人称/第二人称/旁观者 | 80%第一人称+20%第二人称 |
| 语调 | 冷面/温暖/直白/俏皮/临床式 | 温暖+偶尔俏皮吐槽 |
| 标志性短语 | 跨样本重复出现的用词或短语 | "姐妹们听我说""这波真的值" |
| CTA风格 | 结尾行动号召方式 | 软CTA："可以去试试"而非"立即购买" |

### 2. 结构信号

| 信号 | 怎么提取 | 示例 |
|------|---------|------|
| 长度范围 | 各样本字数最小值和最大值 | 300-800字 |
| 列表vs散文 | 偏好哪种表达 | 60%列表+40%散文 |
| 开头模式 | 如何开篇 | 场景设定→痛点→方案 |
| 结尾模式 | 如何收尾 | CTA+开放式提问 |
| 过渡手法 | 段落衔接方式 | "所以""换句话说""划重点" |

### 3. 主题信号

| 信号 | 怎么提取 | 示例 |
|------|---------|------|
| 高频主题 | 跨样本出现的主题 | 护肤成分、平价替代、敏感肌 |
| 隐含受众 | 样本假设的读者 | 18-30岁女性、有护肤需求 |
| 作者立场 | 行业定位和态度 | 实测派、不接广、成分党 |

### 4. 缺失信号（最关键）

记录所有样本中**从未出现**的模式——缺失比存在更能定义风格边界：

| 缺失类型 | 怎么判断 | 示例 |
|---------|---------|------|
| 从未出现的词汇/标点 | 全样本0命中 | 从不用感叹号、从不说"家人们" |
| 从未使用的开头类型 | 全样本0命中 | 从不用反问句开头 |
| 从未触及的语调 | 全样本0命中 | 从不卖惨式、从不说教式 |
| 从未出现的结构 | 全样本0命中 | 从不用"不是X，而是Y"句式 |

每项缺失必须标注"X/Y篇样本"的证据。仅在全部样本一致缺失时列入。

## 声音画像输出模板

```markdown
# 我的声音画像

## 我听起来像谁
[2-3句描述整体风格]

## 语气基调
[3-5个一致命中的调性 + 1-2个从未命中的调性]

## 句子节奏
[平均句长、节奏、段落结构 + 回避模式]

## 开头钩子
[3-5种观察到的Hook类型 + 缺失的Hook类型]

## 标志性表达
[高频短语、口头禅、特色句式]

## 内容禁区
[从不写什么、从不用什么语气、从不碰什么话题]

## 小红书特化
[种草力定位 / 笔记类型偏好 / 封面风格偏好]
```

≤500词。每个章节必须基于样本实证，不得编造。

## 小红书声音画像特化

在标准四维之外，小红书创作者额外关注：

| 维度 | 小红书特化字段 | 说明 |
|------|--------------|------|
| 声音信号 | 种草力定位 | 种草型（热情推荐）/拔草型（冷静避雷）/测评型（中立对比） |
| 声音信号 | 笔记类型偏好 | 教程/好物分享/对比测评/空瓶记/合集/探店 |
| 结构信号 | 封面风格偏好 | 对比图/手写体/大字报/真人出镜/产品拼图 |
| 缺失信号 | 小红书常见但该创作者不用的 | 如：从不用"姐妹们"开头、从不做合集类 |
