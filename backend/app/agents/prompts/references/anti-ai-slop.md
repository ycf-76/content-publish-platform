# AI 廉价感 / AI 味反例清单

> 根本不是"AI 做的"，而是**"没人做设计决定"**——模板选了默认的平均值。
> 对廉价感 → 防影就剔除；对圆润沉闷 → 圆角就剔除。
> *沉闷 = 默认审美平均值。*

> 生成前照本清单主动否决；生成后再自审一轮。

## P0 — 外行一眼识破（最刺眼，绝对禁止）

- 🚫 **蓝→紫渐变**（026 头像 AI tell，源自 Tailwind indigo 默认）。SwanTale 卡的深蓝渐变底就是这个。
- 🚫 **`bg-clip-text` 渐变标题字**（花哨且可变文字）。
- 🚫 **玻璃拟态**（Glassmorphism，半磨砂反光半透明）。
- 🚫 **"居中一切" + hero + 三张并排卡** 的万能模板。
- 🚫 未经修改的默认字体（Inter 直接上）/ 默认主题色。

## P1 — 设计/开发者识破

- 🚫 **emoji 当图标 / emoji 泛滥**（SwanTale 卡就是）。图标改用 Lucide 线性图标(stroke 1.5，直角版 arrow-right/check/plus/slash，避免圆底 smile/heart)，点缀只用 accent/灰/墨，绝不花哨，每张最多 1-2 个。排版中不用图标。
- 🚫 每个 面都 `rounded-2xl shadow-lg`（圆角+阴影防影满屏）。
- 🚫 图标堆在圆底方块、灰底白卡毛玻璃、贴色左边 callout、发光球状或 pastel 图标块。
- 🚫 低对比灰字（正文太小看不清）、默认按钮、CTA 按钮永远备个 `→` 符号。
- 🚫 空白廉价语（颠覆/革命性/一站式/一切可能/说 X 就够卡）。

## P2 — 工艺细节

- 🚫 平滑均布无细节的间距（不用间距 token）、全站同一个 `fade-in-up` 动画。
- 🚫 圆底不统一、边框在圆底处断开、过度圆角、生硬大防影。

## 卡片专属 Bad Smells（直出检查）

- 🚫 像"通用模板贴了篇文章"。
- 🚫 **多张卡底部一大片空**（见 layout-laws，最常见）。
- 🚫 与版面无关的装饰形状(blob/渐圆/水波/贴纸)、装饰性渐变。
- 🚫 截图小到看不清；卡片间距不一致；深底上字色低对比。
- 🚫 1:1 画幅是把 16:9 / 21:9 粗暴裁出来的。

## 按优先级排序 AI 味动作（按评价排序）

1. **先选定立场 + 去token**："clean & modern" 不是方向、是 slop 默认值）——palette/font/radius/texture 全部定死（本系统已替你选好）。
2. **换字体**——单动作最高优先：默认无衬线 → 衬线（Playfair/Fraunces/Noto Serif SC）走杂志立场。
3. **打破"三卡并排"对称**：用非对称、不同细节、不塌缩的块。
4. **颜色语义化**：点缀要有含义（主操作/警示/成功），不叫 gradient-start/end。
5. **删掉所有 emoji**，换线性图标或纯文字。
6. **写显式否决**：在 HTML 注释/CSS 块明确写 "NO gradient, NO shadow, NO emoji, zero radius(墨像)"。
7. **警惕二阶默认**：别用一个 cliché 换另一个（如 Space Grotesk 逃避、万金"暖纸衬线"套所有题材）——按题材的选。

## 渲染前自检（10 秒）

- [ ] 没有蓝紫渐变？（没有花哨文字、玻璃拟态）
- [ ] 一个点缀色（没有蓝绿橙同框），正文非纯黑？
- [ ] 没有 emoji 当图标？（用线性图标或纯文字）
- [ ] 大标题是细字重（不是粗黑体）？
- [ ] 不是"居中一切"？（墨像左对齐）
- [ ] 内容会填满画面？（≥85%，有 flex:1 撑出的空白）→ 渲染后跑 card_audit 复核。
