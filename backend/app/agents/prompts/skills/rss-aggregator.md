# RSS/Newsletter 聚合（rss-aggregator）

> 订阅行业信息源，定期摘要推送。用 trending_search 替代传统 RSS 抓取，LLM 筛选+摘要。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 信息源 | 否 | 指定 RSS 链接/Newsletter/公众号名（未指定则按 Profile 垂类推断） |
| 关注主题 | 否 | 想重点关注的主题关键词 |
| 输出格式 | 否 | 摘要列表/深度解读/对比分析（默认摘要列表） |

## 执行步骤

1. **确定信息源**：按 Profile 垂类匹配行业信息源，或使用用户指定的源
2. **抓取最新内容**：用 trending_search 搜索最新行业资讯
3. **筛选排序**：按与用户关注主题的相关性排序，过滤噪音
4. **摘要生成**：每条资讯 50-100 字摘要，标注来源和时间
5. **输出**：按时间线或主题分组输出

## 平台适配

| 平台 | 关注信息源 | 输出格式 | 时效要求 |
|------|-----------|---------|---------|
| 小红书 | 新消费品牌/种草经济/平台规则/美妆新成分 | 行业周报笔记 | 24小时内 |
| 抖音 | 热点趋势/达人动态/电商规则/流量玩法 | 热点速报 | 实时-6小时 |
| B站 | 创作趋势/分区热点/UP主动态/活动日历 | 选题周报 | 48小时内 |
| 公众号 | 行业深度/政策解读/竞品动态 | 深度摘要 | 1周内 |
| 知乎 | 热门问题/领域动态/圆桌话题 | 选题推荐 | 48小时内 |

**通用规则**：信息源必须可靠（官方/权威媒体/行业头部）

## 规则

1. 信息源必须可靠（官方/权威媒体/行业头部）
2. 摘要必须忠实原文，不曲解不编造
3. 标注每条信息的来源和时间
4. 筛选标准透明（为什么选这 10 条而不是另外 10 条）
