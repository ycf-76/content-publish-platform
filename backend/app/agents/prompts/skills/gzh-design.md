# 微信公众号排版（gzh-design）

> 把内容转成微信公众号兼容的富文本 HTML，支持卡片/引用/分割线等排版元素。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 内容 | 是 | Markdown/纯文本/已有文章 |
| 风格 | 否 | 极简/商务/文艺/活泼（默认极简） |
| 品牌色 | 否 | 主色调（默认 #333333） |

## 执行步骤

1. **内容结构化**：把输入内容拆成标题/段落/列表/引用/图片/代码块等元素
2. **排版设计**：为每个元素选择合适的排版样式（标题层级/引用卡片/列表样式）
3. **HTML 生成**：生成公众号编辑器兼容的 inline-style HTML
4. **视觉优化**：字号/行距/段距/配色/分割线等细节调整
5. **输出**：用 `<!--card-html-->` 包裹完整 HTML

## 平台适配

| 源平台 | 转换策略 | 内容调整 | 排版差异 |
|--------|---------|---------|---------|
| 小红书→公众号 | 笔记扩展为长文 | 加深度/加数据/加引用 | 图文→富文本排版 |
| 知乎→公众号 | 回答转文章 | 调语气/加排版/精简引用 | Markdown→inline HTML |
| B站→公众号 | 视频转图文 | 口播转文字/加截图 | 时间线→段落结构 |
| 抖音→公众号 | 短内容扩展 | 加背景/加分析/加观点 | 碎片→体系化 |
| 通用 | Markdown→公众号HTML | 保持语义/调格式 | 支持卡片/引用/分割线 |

**公众号优势**：不受字数限制，适合深度内容/教程/测评长文

## 规则

1. HTML 必须使用 inline style（公众号不支持 class）
2. 图片宽度不超过 677px（公众号正文区宽度）
3. 正文字号 15-17px，行距 1.75-2.0
4. 不使用公众号不支持的 CSS（flex/grid/animation）
5. 用 `<!--card-html-->` 标记包裹
