# 直播策划 + 话术（livestream）

> 为直播生成完整方案，覆盖主题策划、流程编排、全场话术脚本，适配带货/知识/娱乐多场景。

## 输入

| 参数 | 必填 | 说明 |
|------|------|------|
| 直播类型 | 是 | 带货直播 / 知识分享 / 娱乐互动 / 品牌活动 |
| 直播主题 | 否 | 未指定时根据赛道和热点推荐 |
| 直播时长 | 否 | 预计时长（默认 2 小时） |
| 商品/内容清单 | 否 | 带货需商品列表，知识直播需分享主题 |
| 目标平台 | 否 | 抖音 / 快手 / 视频号 / 淘宝直播 / 小红书 |

## 执行步骤

领域知识统一见 `references/livestream-playbook.md`。

1. **确认直播类型和场景**：识别类型，明确核心目标；未指定主题时推荐 3 个选项
2. **流程架构设计**：按 playbook「一、流程架构」的波浪式结构设计整体节奏；带货额外规划商品上架顺序
3. **开场白设计**：前 30 秒抓人，含打招呼+亮点预告+互动指令
4. **主体话术编写**：按直播类型套用对应话术结构（带货/知识/娱乐，见 playbook「三、主体话术结构」）
5. **互动环节设计**：规划 3-5 个互动节点穿插主体，每个配完整话术
6. **过渡语和节奏控制**：设计环节过渡语，标注节奏/情绪/动作提示
7. **收尾和引导关注**：总结、预告、引导关注、感谢；带货加福利冲刺
8. **应急预案编写**：冷场/负面评论/技术故障/翻车的应对话术
9. **开播前准备清单**：设备/内容/平台/团队/状态五类

## 平台适配

| 平台 | 直播风格 | 话术要点 | 合规 | 互动权重 |
|------|---------|---------|------|---------|
| 小红书 | 种草分享，偏软 | 考虑回放观众体验 | 禁站外导流/禁虚假宣传/禁刷单 | 点赞>评论>分享>打赏 |
| 抖音 | 带货+娱乐，节奏快 | 前3秒留人，每5分钟一波福利 | 禁虚假价格/禁站外导流 | 评论>点赞>打赏>分享 |
| B站 | 知识/游戏/聊天，偏深度 | 可长段讲解，弹幕互动 | 禁刷弹幕/禁违规内容 | 弹幕>评论>充电>分享 |
| 视频号 | 生活/知识/带货 | 偏真实感，少套路 | 禁站外导流/禁虚假宣传 | 点赞>评论>分享 |
| 快手 | 老铁文化，接地气 | 多互动多连麦，信任感优先 | 禁虚假宣传/禁刷单 | 评论>点赞>打赏 |

## Profile 感知

- 有 Profile：读 identity 调整话术风格，读 audience 定制互动方式，读 platforms 适配平台规则
- 无 Profile：话术用通用口语风格，流程用通用模板，附注"提供画像可获得更贴合人设的话术风格"

## 规则

1. 话术必须口语化，避免书面语和官方说辞
2. 每段话术不超过 200 字，保持直播即时感
3. 催单话术不可虚假宣传（禁止"全网最低价"等绝对化用语）
4. 带货话术需符合广告法，不使用违禁词
5. 流程设计必须有弹性，标注可延长/缩短的环节
6. 互动环节不少于 3 个，间隔不超过 30 分钟
7. 话术中标注明确时间节点，方便主播和场控对表
