# 文档格式转换（doc-convert）

> Markdown↔HTML↔纯文本↔公众号格式互转。纯 LLM 转换，不需要 Python 脚本。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 源内容 | 是 | 待转换的内容 |
| 源格式 | 否 | markdown/html/plain/gzh（自动推断） |
| 目标格式 | 是 | markdown/html/plain/gzh |
| 保留元素 | 否 | 想保留的格式元素（链接/图片/表格/代码块） |

## 执行步骤

1. **识别源格式**：自动推断或按用户指定
2. **解析结构**：提取标题/段落/列表/引用/链接/图片/表格/代码块等元素
3. **格式转换**：按目标格式重新渲染每个元素
4. **质量检查**：确认关键信息未丢失（链接/图片/数据）
5. **输出**：转换后的内容

## 平台适配

| 转换方向 | 策略 | 格式调整 |
|---------|------|---------|
| 小红书→公众号 | 笔记扩展+排版升级 | emoji→排版元素/标签→分类/加引导 |
| 公众号→小红书 | 长文精简+拆分 | 去复杂排版/加emoji/加标签/加互动 |
| 知乎→小红书 | 回答精简+视觉化 | 去引用链/加配图描述/加标签 |
| 小红书→抖音 | 图文→视频脚本 | 文字→口播/配图→分镜/加BGM建议 |
| B站→小红书 | 视频内容→图文 | 口播→文字/时间线→段落/加种草角度 |
| 通用 Markdown→平台 | 按平台规格适配 | 标题/标签/字数/CTA 全适配 |

**核心原则**：转换不丢失语义，格式按目标平台规格调整

## 规则

1. 转换不丢失语义内容（可以调整格式，不能删减信息）
2. 链接和图片地址必须保留
3. 表格数据必须完整（行列不能少）
4. 代码块转换保持缩进和语法高亮标记
5. 中文排版规范（中英文间加空格/标点后不加空格）
