# 平台算法动态追踪（algorithm-updates）

> 聚合中文社媒平台的算法更新、推荐机制变化与流量规则调整，输出结构化简报。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| platforms | 否 | 目标平台列表（默认全部 6 个） |
| time_range | 否 | 近一周 / 近一月 / 近三月（默认近一月） |
| focus | 否 | 流量分发 / 内容审核 / 变现规则 / 全部（默认全部） |

## 执行步骤

1. **确定范围**：解析平台列表、时间范围和关注方向；有 Profile 时优先覆盖活跃平台
2. **多维度搜索**：用 trending_search 搜索各平台"算法更新""流量规则""推荐机制"等关键词
3. **整理变化**：每个平台整理近期变化条目，标注来源和时间
4. **分析影响**：每条变化分析对创作者的具体影响（流量/曝光/变现/合规）
5. **应对建议**：给出可操作的建议（如调整发布时间/内容形式/互动策略）
6. **跨平台趋势**：识别多个平台共同出现的规则变化方向
7. **输出简报**：每个平台一节（变化→影响→建议）+ 跨平台趋势

## 平台适配

| 平台 | 重点追踪 | 特有规则 | 诊断联动 |
|------|---------|---------|---------|
| 小红书 | 搜索权重/笔记推荐/直播流量/商业流量 | 软广识别/搬运检测/流量池分级/薯条规则 | account-diagnosis |
| 抖音 | 推荐算法/完播率权重/电商流量/同城 | 流量池赛马/创作者分/DOU+规则 | account-diagnosis |
| B站 | 推荐算法/分区流量/创作激励/充电 | 稿件审核/分区权重/创作分 | account-diagnosis |
| 微博 | 热搜算法/时间线/超话流量/广告 | 水军检测/限流规则/蓝V权重 | account-diagnosis |
| 知乎 | 推荐算法/搜索权重/盐选/圆桌 | 折叠规则/利益相关/专业认证 | account-diagnosis |

## Profile 感知

- 有 Profile：优先追踪 platforms 活跃平台的算法变化
- 无 Profile：覆盖全部 6 个平台

## 规则

1. 只关注平台机制变化，不关注内容热点（那是 trending-topics）
2. 变化条目必须有来源，不编造不存在的算法更新
3. 影响分析必须具体到创作者可感知的层面
4. 应对建议必须可操作，不说"关注平台动态"这种空话
5. 标注信息时效性，超过 3 个月的变化标注"可能已过时"
