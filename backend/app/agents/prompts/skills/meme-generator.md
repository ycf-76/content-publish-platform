# 表情包/Meme 生成（meme-generator）

> 基于热门模板或原创概念，生成表情包文案和 AI 生图 Prompt。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 概念/文案 | 是 | 想表达的情绪/场景/梗 |
| 风格 | 否 | 可爱/沙雕/文艺/职场/情侣（默认按概念推断） |
| 数量 | 否 | 生成几个方案（默认 3） |

## 执行步骤

1. **概念拆解**：把用户概念拆成"画面+文字+情绪"三要素
2. **模板匹配**：从经典 Meme 模板中匹配最合适的（Doge/悲伤蛙/熊猫头/小黄人等）
3. **文案创作**：为每个方案写 2-3 组文案（配图文字+底部文字）
4. **AI 生图 Prompt**（原创方案）：写出可执行的图片生成 Prompt
5. **输出**：每个方案包含模板/文案/Prompt

## 平台适配

| 平台 | 风格偏好 | 热门主题 | 使用场景 | 尺寸 |
|------|---------|---------|---------|------|
| 小红书 | 可爱>文艺>沙雕 | 猫狗/美食/穿搭/职场 | 评论区互动/笔记配图 | 1080x1080 |
| 抖音 | 沙雕>可爱>职场 | 热梗/表情包/方言 | 评论区/私信/视频配图 | 1080x1080 |
| B站 | 沙雕>二次元>职场 | 鬼畜/番剧/游戏/学习 | 弹幕/评论区/动态 | 任意 |
| 微博 | 沙雕>热点>可爱 | 热搜梗/明星/社会 | 转发/评论/配图 | 1:1或16:9 |
| 微信 | 可爱>职场>文艺 | 打工人/猫狗/节日 | 聊天/朋友圈/群 | 300x300 |

**通用合规**：不涉及政治/宗教/歧视/低俗内容

## 规则

1. 文案简短有力（10 字以内为佳）
2. 情绪表达必须明确（一眼看出在表达什么）
3. 不使用有版权争议的 IP 形象
4. 不生成可能引起争议或冒犯的内容
