# 资讯情报聚合（news-intelligence）

> 从中文行业媒体与垂类资讯源抓取深度内容，按创作者赛道过滤，
> 生成结构化中文情报简报，并给出可操作的选题方向。

## 与 trending-topics 的分工

| | trending-topics | news-intelligence（本 Skill）|
|---|---|---|
| 抓什么 | 实时热搜榜 | 行业媒体深度文章/快讯 |
| 时效 | 分钟级，追热点 | 日级，看行业趋势 |
| 用途 | 蹭热点、快速二创 | 深度选题、行业观察 |

## 输入

- **赛道/领域**：自媒体运营 / 科技数码 / 商业财经 / AI / 时事话题（有 Profile 时自动提取）
- **关键词**：如 "AI"、"融资"、"新消费"（用于过滤）
- **深度**：快速浏览 / 深度分析（默认快速）
- **数量**：每源 5-15 条（默认 10）

## 执行步骤

1. **选择信息源**：按赛道选择源组合（36kr/虎嗅/钛媒体→科技商业；新榜/卡思数据→自媒体运营）
2. **抓取与过滤**：用 trending_search 工具搜索赛道关键词，按时间排序，去重
3. **生成摘要**：每条资讯生成一句话中文摘要 + 洞察（背景/影响/与创作者关系）
4. **选题方向**：基于资讯推荐 3-5 个可操作选题，每个标注切入角度 + 建议平台/形式
5. **输出简报**：要闻速览 + 选题方向

## 平台适配

| 平台 | 优先资讯方向 | 选题标注 | 过滤策略 |
|------|-------------|---------|---------|
| 小红书 | 种草经济/新消费/美妆趋势/平台规则 | 适合笔记类型（测评/清单/教程） | 按垂类过滤 |
| 抖音 | 流量玩法/电商规则/达人动态/热点趋势 | 适合视频类型（剧情/测评/教程） | 按账号定位过滤 |
| B站 | 分区动态/创作工具/活动日历/政策变化 | 适合视频类型（深度/教程/盘点） | 按分区过滤 |
| 微博 | 热搜趋势/舆情动态/政策变化 | 适合图文类型（热点/观点/资讯） | 按关注领域过滤 |
| 知乎 | 领域热点/圆桌话题/盐选动态 | 适合回答类型（深度/对比/科普） | 按专业领域过滤 |

## Profile 感知

- 有 Profile：按 identity 垂类自动选择赛道，按 audience 兴趣过滤
- 无 Profile：覆盖主流赛道，让用户选择

## 规则

1. 不抓热搜榜（那是 trending-topics 的职责）
2. 摘要必须一句话，洞察必须具体可操作
3. 选题方向至少 3 个，每个标注切入角度
4. 信息源标注出处，不编造不存在的文章
