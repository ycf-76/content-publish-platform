# 科研论文解读（paper-explainer）

> 把一篇论文讲成普通人/同行都爱看的图文或视频脚本。纯 LLM 解读，不需要 PDF 解析脚本。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 论文 | 是 | arXiv 链接/DOI/论文全文粘贴 |
| 目标形态 | 否 | 图文（默认）/ 视频脚本 / 两者 |
| 受众深度 | 否 | 大众科普（默认）/ 同行向 |
| 重点章节 | 否 | 想重点解读的部分 |

## 执行步骤

1. **论文解析**：提取标题/摘要/问题/方法/实验/结论/关键图表
2. **核心贡献提炼**：用一句话说清这篇论文解决了什么问题、怎么解决的、效果如何
3. **通俗化转译**：把学术语言翻译成大众能理解的表达（类比/举例/可视化描述）
4. **结构化解读**：
   - 为什么要研究这个问题？（动机/背景）
   - 之前的方法有什么问题？（前序工作）
   - 这篇论文的核心创新是什么？（方法）
   - 效果有多好？（实验/数据）
   - 还有什么局限？（讨论/未来工作）
5. **产出内容**：按目标形态输出图文或视频脚本

## 平台适配

| 平台 | 主力形态 | 字数 | 标题钩子 | 通俗化程度 | 互动引导 |
|------|---------|------|---------|-----------|---------|
| 小红书 | 图文笔记 | 1500-3000字 | "这篇论文改变了XX" | 每个术语都要解释 | "收藏备用" |
| B站 | 视频解读 | 5-15分钟 | "这篇论文颠覆了XX认知" | 适度通俗，保留关键公式 | 一键三连 |
| 知乎 | 长文解读 | 3000-5000字 | "论文精读：XX的突破" | 同行向可保留术语 | "赞同+收藏" |
| 公众号 | 深度图文 | 3000-5000字 | "最新研究：XX竟然是错的" | 大众科普，类比为主 | "在看+分享" |
| 抖音 | 短视频 | 60秒内 | "科学家发现XX" | 极度通俗，只讲结论 | "关注看更多" |

**通用规则**：论文解读内容收藏率普遍偏高，结尾引导收藏

## 规则

1. 不曲解论文结论，通俗化不等于简化到失真
2. 关键数据必须标注来源（论文第X页/Table X）
3. 局限性必须提及，不只讲好的
4. 专业术语首次出现必须解释
5. 不编造论文中没有的实验结果或数据
