# 品牌/联名合作方案（collab-proposal）

> 根据合作需求，查询 KOL 定价表计算报价区间，用平台系数公式预估 KPI，输出结构化提案。

## 输入

| 参数 | 必填 | 说明 |
|------|------|------|
| 合作方信息 | 是 | 品牌名称/合作方名称、产品或服务描述 |
| 合作模式 | 否 | 商单(A) / 联名(B)，未指定时自动判断 |
| 预算范围 | 否 | 品牌方预算上限，用于反向匹配内容形式 |

**自动判断**：含"报价""商单""品牌植入""接广告"走模式 A；含"联名""联动""博主合作""互推"走模式 B。

## 执行步骤

1. **解析意图**：识别走模式 A（商单）还是 B（联名），提取品牌/产品/预算
2. **确定 KOL 层级**：根据粉丝量查 `references/kol-pricing-guide.md` 第 1 节层级表
3. **计算报价区间（模式 A）**：查第 2 节基础报价 → 叠加第 3 节调整因子 → CPE 校验
4. **预估 KPI**：按第 5 节公式逐层计算（曝光→互动→转化），给区间不给单值
5. **设计内容方案**：推荐 2-3 种内容形式，每种标注形式/创意方向/植入方式
6. **制定排期**：制作周期 + 推荐发布时间 + 审核预留
7. **联名补充（模式 B）**：双方数据对比 + 受众重叠度 + 内容分工矩阵 + 双方 KPI
8. 输出结构化提案

## 平台适配

| 平台 | 报价溢价因子 | 合规要点 | KPI侧重 |
|------|-------------|---------|---------|
| 小红书 | 蒲公英+20-30%/种草笔记+15-20%/合集+10% | 需声明合作，未声明限流 | CPE/收藏率/种草转化 |
| 抖音 | 星图+15-25%/挂车+10-15% | 需走星图，私下合作风险 | ROI/GPM/转粉率 |
| B站 | 花火+10-20%/充电+5% | 需声明推广，UP主自律 | 播放完成率/互动率 |
| 微博 | 微任务+15-20% | 需声明广告，水军严打 | 互动率/转评赞/曝光 |
| 公众号 | 广告主直投为主 | 需声明推广，阅读数透明 | 打开率/完读率/转化 |

## Profile 感知

- 有 Profile：从 identity 读粉丝量/垂类，从 platforms 读互动率，从 audience 读受众画像
- 无 Profile：报价给全层级通用区间，KPI 用行业中位数，标注"仅供参考"

## 规则

1. 报价必须有据可查——每个数字须能追溯到定价表 + 调整因子
2. KPI 必须标注公式——每个预估值旁标注计算过程
3. 区间优于单值——报价和 KPI 一律给保守值-乐观值区间
4. 缺信息时追问，不编造
5. CPE 校验必做——不合理时标注警告
6. 内容形式至少 2 个，每种标注优劣
7. 转化预估需谨慎——无直接转化链路不强行预估
