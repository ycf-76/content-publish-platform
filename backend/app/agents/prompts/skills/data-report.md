# 数据可视化报告（data-report）

> 把用户数据转成自包含 HTML 可视化报告（KPI 卡片 + 图表 + 洞察 + 数据表）。
> 纯 LLM + HTML/CSS/JS 输出，不需要 Python 脚本。

## 输入

- 数据：CSV/JSON/Excel 数据（粘贴或描述）
- 可选：报告标题、想突出的 KPI、图表类型偏好

## 执行步骤

1. **数据概览**：读取数据，识别列名/数据类型/行数/缺失值
2. **KPI 提取**：自动识别关键指标（数值列的均值/总计/同比/环比）
3. **图表设计**：按数据类型选择合适的图表（时间序列→折线/分类→柱状/占比→饼图/分布→直方图）
4. **洞察撰写**：从数据中提炼 3-5 条关键洞察（趋势/异常/对比/预测）
5. **HTML 组装**：KPI 卡片 + 图表(ECharts CDN) + 洞察文字 + 数据表
6. **输出**：用 `<!--card-html-->` 包裹完整 HTML

## 平台适配

| 平台 | 报告场景 | 核心 KPI | 视觉风格 |
|------|---------|---------|---------|
| 小红书 | 月度运营/内容表现/竞品/粉丝画像 | 互动率/收藏率/涨粉率/转化率 | 暖色调/大数字/简洁卡片 |
| 抖音 | 播放量分析/完播率/转化漏斗 | 播放量/完播率/互动率/转粉率 | 深色/动感/数据大字 |
| B站 | 播放数据/粉丝画像/稿件对比 | 播放量/弹幕数/硬币/追番 | 蓝粉色调/B站风 |
| 公众号 | 阅读分析/粉丝增长/图文对比 | 阅读量/打开率/分享率/在看率 | 商务/简洁/品牌色 |
| 知乎 | 回答数据/专栏分析/盐选收益 | 赞同数/收藏数/浏览量/收益 | 知乎蓝/专业感 |

**通用规则**：报告 HTML 自包含，可截图分享；不用蓝紫科技渐变风

## 规则

1. 数据必须真实，不编造不存在的数据点
2. 图表类型必须匹配数据特征（时间序列不用饼图）
3. 洞察必须有数据支撑，不说"数据表现良好"
4. HTML 自包含（CSS/JS 内联或走 CDN），可离线打开
5. 用 `<!--card-html-->` 标记包裹，不用 ```html 代码块
