# 营销策划（campaign-planner）

> 产出一份可落地的营销活动方案，覆盖目标→节奏→内容矩阵→玩法→资源→风险→复盘指标。
> 领域方法在 `references/campaign-frameworks.md`，本文件只讲流程。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 活动类型 | 是 | 节日营销 / 电商大促 / 新品发布 / 活动造势 / 周年庆 |
| 目标 | 推荐 | 涨粉 / 转化 / 声量 / 拉新 / 清库存 |
| 时间 | 推荐 | 活动日期 / 大促节点 |
| 资源 | 可选 | 预算、可用平台、是否有 KOL/达人 |

信息不全时先补齐关键项（类型/目标/时间），再出方案。

## 执行步骤

1. **判定活动类型与核心目标**，读 `references/campaign-frameworks.md`「一、目标→打法映射」确定主打法
2. **搭营销节奏**：按「二、营销节奏模型」拆成 预热期 / 爆发期 / 返场期，每阶段定目标、内容重点、发布密度
3. **排内容矩阵**：按「三、内容矩阵」把各阶段 × 各平台 × 内容形式排成表
4. **设计互动玩法**：从「四、玩法库」选契合目标的 2-3 个玩法，说明机制与目的
5. **资源分配**：按「五、KOL 分层与预算」给达人分层建议与预算大致比例
6. **风险与合规**：按「六、风险与合规红线」列常见坑
7. **效果指标**：按「七、效果指标」给分阶段可量化 KPI
8. 输出结构化方案：目标 → 节奏排期表 → 内容矩阵表 → 玩法 → 资源/预算 → 风险 → KPI

## 平台适配

| 平台 | 预热→爆发→返场节奏 | 内容类型混搭 | 合规要点 |
|------|-------------------|-------------|---------|
| 小红书 | 素人铺量→腰部种草→晒单UGC | 测评40%+清单25%+教程20%+晒单15% | 合作需声明"广告"/"合作" |
| 抖音 | 挑战赛预热→达人爆发→UGC返场 | 剧情40%+测评25%+教程20%+合集15% | 不站外导流/不刷单 |
| B站 | 预告片→正片爆发→二创返场 | 测评40%+教程25%+对比20%+盘点15% | 不虚假数据/不买粉 |
| 微博 | 话题预热→KOL爆发→热搜返场 | 图文40%+视频25%+九图20%+长文15% | 不买热搜/不刷量 |
| 公众号 | 预告→深度文→互动返场 | 深度50%+教程25%+盘点15%+互动10% | 不诱导分享/不刷阅读 |

## Profile 感知

- 有 Profile：目标/平台/调性贴合画像；玩法与文案语气对齐 style；合规遵守 preferences 底线
- 无 Profile：按活动类型给通用方案，标注需用户补充预算/平台/产品信息以精化

## 规则

1. 方案必须可落地：给具体节奏排期、平台分工、玩法机制，不写空泛口号
2. 节奏是核心——预热蓄水、爆发集中、返场收尾，别把火力平摊
3. 玩法服务目标：转化型重优惠/紧迫感，声量型重话题/参与感
4. 明确风险与合规红线，不建议违规诱导玩法
5. 给可量化 KPI 与复盘口径，方案闭环到效果评估
