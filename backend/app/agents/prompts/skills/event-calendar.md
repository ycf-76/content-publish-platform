# 节日/节点日历（event-calendar）

> 查询未来 N 天的节日、纪念日、电商节点、行业事件，为创作者提供内容蹭点和提前准备的时间窗口。

## 输入

| 参数 | 必填 | 说明 |
|------|------|------|
| 时间范围 | 否 | 未来 N 天（默认 30 天） |
| 赛道/领域 | 否 | 筛选与特定赛道相关的节点 |
| 节点类型 | 否 | 节日/电商/行业/考试/体育（默认全部） |

## 执行步骤

1. **确定时间范围和赛道**：解析输入参数；有 Profile 时按 identity 垂类筛选
2. **查询节点数据**：用 LLM 知询未来 N 天的节日/电商/行业节点（LLM 内置常见节点知识）
3. **蹭点价值评估**：每个节点按 5 星评估蹭点价值（受众关注度 x 内容适配度 x 竞争强度）
4. **内容方向建议**：每个高价值节点给一句话内容方向建议
5. **提前准备提醒**：标注需要提前 N 天准备的节点（大促需提前 2 周，节日需提前 1 周）
6. **输出日历**：近期重点节点(7天内) + 未来30天总览 + 高价值节点详解

## 平台适配

| 平台 | 蹭节点主力 | 电商节点 | 节日节点 | 内容方向 |
|------|-----------|---------|---------|---------|
| 小红书 | 节日送礼/大促种草/换季清单/考试季干货 | 618/双11/年货节/38/99/双12 | 情人节/母亲节/七夕/圣诞/春节 | 节日→送礼清单；大促→提前种草攻略 |
| 抖音 | 热点蹭流量/大促带货/节日氛围 | 618/双11/年货节/38/99 | 同上 | 节日→氛围视频；大促→直播带货 |
| B站 | 节日特辑/大促测评/开学季/考试季 | 618/双11/数码新品季 | 情人节/中秋/国庆/春节 | 节日→特别企划；大促→横评对比 |
| 微博 | 热点蹭热搜/节日话题/大促盘点 | 618/双11/年货节 | 全节日覆盖 | 节日→话题互动；大促→品牌盘点 |
| 知乎 | 节日科普/大促选购指南/考试季 | 618/双11/数码季 | 情人节/中秋/国庆 | 节日→深度科普；大促→选购攻略 |

## Profile 感知

- 有 Profile：按 identity 垂类筛选相关节点，按 audience 兴趣调整蹭点价值
- 无 Profile：覆盖全部节点类型

## 规则

1. 节点数据必须准确（日期/名称不能错）
2. 蹭点价值评估必须结合赛道，不泛泛给星
3. 内容方向建议必须具体，不说"做节日相关内容"
4. 提前准备天数必须合理（大促 2 周，普通节日 1 周，热点事件 3 天）
