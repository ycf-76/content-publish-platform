# 图表可视化（chart-visualization）

> 用 ECharts 生成单张图表 HTML。25+ 图表类型，自包含可离线打开。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 数据 | 是 | 图表数据（JSON/CSV/描述） |
| 图表类型 | 否 | 折线/柱状/饼图/散点/雷达/热力图/漏斗/桑基等（自动推断） |
| 标题 | 否 | 图表标题 |
| 样式 | 否 | 配色/尺寸/主题 |

## 执行步骤

1. **数据解析**：识别数据结构和特征
2. **类型推断**：未指定类型时按数据特征自动选择（时间序列→折线/分类→柱状/占比→饼图/多维→雷达）
3. **ECharts 配置生成**：生成完整的 ECharts option JSON
4. **HTML 组装**：自包含 HTML（ECharts CDN + option + 渲染代码）
5. **输出**：用 `<!--card-html-->` 包裹

## 平台适配

| 平台 | 图表场景 | 视觉风格 | 尺寸基准 | 交互 |
|------|---------|---------|---------|------|
| 小红书 | 数据对比/趋势/品类占比/粉丝画像 | 暖色调/大字号/简洁 | 375px竖屏 | tooltip+缩放 |
| 抖音 | 数据对比/增长曲线/排行榜 | 深色/动感/大数字 | 1080px | 静态为主 |
| B站 | 技术对比/性能数据/时间线 | 蓝粉色调/专业 | 1920px | 完整交互 |
| 公众号 | 数据报告/趋势分析/对比 | 商务/品牌色/简洁 | 677px | 静态 |
| 知乎 | 数据论证/对比分析/趋势 | 知乎蓝/专业/清晰 | 720px | tooltip |

**通用规则**：不用蓝紫科技渐变风；数据必须真实

## 规则

1. 图表类型必须匹配数据特征
2. 数据必须真实，不编造数据点
3. ECharts option 必须完整可运行
4. HTML 自包含（JS 走 CDN），可离线打开
5. 用 `<!--card-html-->` 标记包裹
