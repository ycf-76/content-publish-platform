# 发布数据归因分析（publish-analytics）

> 从发布数据中分析时间、标签、类型、增长四个维度，输出结构化归因报告。

## 输入

用户指定分析模式（可组合）：

- **模式 A — 最佳发布时间**：分析发布时段与互动数据的关系
- **模式 B — 标签效果分析**：评估标签对内容表现的影响
- **模式 C — 内容类型对比**：按内容类型对比各项指标
- **模式 D — 增长归因**：关联发布事件与粉丝增长

未指定模式时默认执行 A + B + C。

## 执行步骤

1. **获取发布数据**：从 data-tracker 快照或用户提供的 CSV/口述数据中读取
2. **模式 A 最佳发布时间**：按时段聚合互动数据，找出高表现时段
3. **模式 B 标签效果**：统计各标签出现频率与对应互动均值，找出高效标签
4. **模式 C 内容类型对比**：按图文/视频/合集等类型对比各项指标
5. **模式 D 增长归因**：关联发布事件时间线与粉丝增长拐点
6. **输出归因报告**：各模式结论 + 可执行优化建议

## 平台适配

| 平台 | 最佳发布时间 | 标签效果 | 内容类型差异 | 增长归因 |
|------|-------------|---------|-------------|---------|
| 小红书 | 工作日12-13/18-20，周末10-11/20-22 | 标签搜索权重高，直接影响搜索流量 | 图文收藏率高，视频互动率高 | 涨粉与"被收录"强相关 |
| 抖音 | 工作日12-13/18-22，周末全天 | 话题标签影响推荐池 | 短视频完播率是核心 | 涨粉与完播率/互动率相关 |
| B站 | 12-13/18-22 | 标签影响分区推荐 | 中长视频深度内容涨粉稳 | 涨粉与播放完成率/追番相关 |
| 知乎 | 9-10/12-13/20-22 | 话题影响搜索和推荐 | 长文赞同率高，视频曝光大 | 涨粉与赞同/收藏相关 |
| 微博 | 8-9/12-13/20-22 | 话题影响热搜曝光 | 图文/九图/视频各有场景 | 涨粉与转评赞相关 |

## Profile 感知

- 有 Profile：按 platforms 确定分析平台，按 identity 垂类调整归因维度
- 无 Profile：默认小红书

## 规则

1. 数据驱动，每个结论必须有数据支撑
2. 归因不等于因果——标注"相关"而非"导致"
3. 建议必须可操作，不说"优化发布时间"而说"建议在 18:00-20:00 发布"
4. 样本量不足时标注"数据有限，结论仅供参考"
