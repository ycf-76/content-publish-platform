# 电商商品视觉方案（ecom-details-image）

> 生成电商商品视觉方案：主图概念、场景图、详情页视觉方向和 AI 生图 Prompt。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 商品信息 | 是 | 商品名/品类/核心卖点/目标人群 |
| 视觉风格 | 否 | 高级感/温馨/科技/自然/潮流（默认按品类推断） |
| 图片数量 | 否 | 需要几张图（默认5：1主图+4详情图） |
| 平台 | 否 | 小红书/淘宝/京东/拼多多（默认小红书） |

## 执行步骤

1. **判断场景类型**：按商品品类匹配视觉模板（美妆/食品/3C/服饰/家居/母婴）
2. **主图概念设计**：5个主图方案（白底图/场景图/对比图/氛围图/创意图），每个含构图+光线+色调描述
3. **详情页视觉方向**：信息图结构+字体搭配+色板+排版节奏
4. **AI 生图 Prompt**：为每张图写出可执行的 Prompt（正向描述+负向约束+参数建议）
5. **审美对齐**：遵守去 AI 廉价感原则——禁蓝紫科技渐变、禁 emoji 当图标、字大字细、留白克制

## 平台适配

| 平台 | 主图策略 | 详情页形态 | Prompt 风格 | 合规要点 |
|------|---------|-----------|-----------|---------|
| 小红书 | 场景图>白底图，生活化优先 | 笔记体（场景+体验+效果） | 暖光/自然/生活场景 | 真实效果，不夸大 |
| 淘宝 | 白底图+场景图，电商化 | 传统详情页（卖点+参数+评价） | 棚拍/精修/白底 | 不虚假宣传 |
| 京东 | 白底图为主，品质感 | 参数详情+对比图 | 精修/质感/参数标注 | 正品保障 |
| 拼多多 | 白底图+价格感 | 简洁详情+买家秀 | 简洁/价格感/团购 | 不虚假低价 |
| 抖音 | 短视频+封面图 | 短视频展示+小黄车 | 动感/真实/使用场景 | 不夸大效果 |

**通用规则**：产品效果需真实，不夸大不 P 图过度；色板按品类匹配

## 规则

1. Prompt 必须具体可执行（含构图/光线/色调/风格关键词）
2. 每张图的 Prompt 不超过 200 词
3. 负向约束必须包含"去 AI 味"关键词
4. 色板必须与商品品类匹配（美妆偏粉金/食品偏暖橙/3C偏深灰银）
5. 不编造不存在的拍摄场景或道具
