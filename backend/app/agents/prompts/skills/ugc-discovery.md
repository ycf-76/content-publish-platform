# UGC 内容发现（ugc-discovery）

> 搜索与创作者品牌/账号相关的用户生成内容，发现粉丝内容、测评、提及和社区讨论。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| brand_keywords | 是 | 品牌名/账号名，可多个 |
| platforms | 否 | 聚焦平台（小红书/B站/微博/知乎/抖音），默认全平台 |
| content_type | 否 | reviews / mentions / complaints / all（默认 all） |
| time_range | 否 | recent / this_month / this_quarter（默认 recent） |

## 执行步骤

1. **构建搜索关键词组合**：`"{账号名} 推荐"` / `"{账号名} 测评"` / `"{品牌名} 体验"` / `"{账号名} 同款"`
2. **平台搜索**：用 trending_search 逐平台搜索，按 platforms 参数聚焦
3. **情感分类**：将发现内容分为正面/中性/负面
4. **筛选高价值 UGC**：按互动量、内容质量、传播潜力排序
5. **生成互动建议**：对高价值 UGC 给出具体互动动作（转发/评论/联动/感谢）
6. **负面反馈标记**：对负面内容标注严重程度和建议回应方式

## 平台适配

| 平台 | 搜索策略 | UGC主力类型 | 授权建议 | 负面关注点 |
|------|---------|-----------|---------|-----------|
| 小红书 | `"{品牌} site:xiaohongshu.com"` | 种草笔记/晒单/测评 | 优质晒单→授权买家秀 | "虚假种草"/"广告"指控 |
| 抖音 | `"{品牌} site:douyin.com"` | 开箱/测评/使用教程 | 优质UGC→合辑引用 | "水军"/"刷评"指控 |
| B站 | `"{品牌} site:bilibili.com"` | 测评/对比/体验 | 优质二创→授权转发 | "恰饭"/"收钱"指控 |
| 微博 | `"{品牌} site:weibo.com"` | 话题讨论/晒单/吐槽 | 热门UGC→话题引用 | "水军"/"控评"指控 |
| 知乎 | `"{品牌} site:zhihu.com"` | 回答/评测/对比 | 优质回答→引用 | "软文"/"利益相关" |

## Profile 感知

- 有 Profile：用 identity 账号名和 platforms 活跃平台自动填充搜索参数
- 无 Profile：要求用户输入 brand_keywords

## 规则

1. 搜索关键词至少 3 组，覆盖不同角度
2. 不编造不存在的 UGC 内容
3. 负面反馈必须标注，不能只报喜不报忧
4. 互动建议必须具体可操作，不说"建议互动"这种空话
