# 视频制作策略（video-strategy）

> 视频制作策略与工具选型，覆盖 AI 视频生成模型对比、脚本结构设计、制作流程规划。

## 输入

- 视频目标（产品演示/解说/社媒短视频/广告/教程/种草）
- 目标平台（抖音/B站/快手/视频号/小红书/YouTube）
- 现有素材（截图、录屏、脚本、品牌素材）
- 预算和技术栈约束

## 执行步骤

1. **收集上下文**：确认视频类型/目标平台/呈现方式/素材情况/复用需求/预算
2. **选择制作方案**：按场景推荐最合适的制作路径
3. **平台适配规格**：分辨率/时长/画幅比/帧率
4. **制作流程规划**：从素材准备到成片的完整步骤
5. **系列规划**（如需）：如果是系列视频，规划主题线+发布节奏+内容矩阵

## 制作方案对比

| 方案 | 适用场景 | 工具 | 依赖 |
|------|---------|------|------|
| 手机拍摄+剪辑 | 真人出镜/Vlog/种草 | 剪映/CapCut | 零 |
| 录屏+旁白 | 教程/演示/测评 | OBS+剪映 | 零 |
| AI 生图+剪辑 | 产品展示/概念视频 | Midjourney+剪映 | AI API |
| AI 数字人 | 真人呈现/多语言 | HeyGen/D-ID | API key |
| 程序化视频 | 模板化/数据驱动 | HTML+CSS+JS | 零 |

## 平台适配

| 平台 | 画幅 | 主力时长 | 主力类型 | 拍摄建议 | 系列节奏 |
|------|------|---------|---------|---------|---------|
| 小红书 | 9:16竖版 | 15-60秒 | 种草/教程/测评 | 手机+自然光，真实感优先 | 3-5期，每周1-2期 |
| 抖音 | 9:16竖版 | 15-60秒 | 娱乐/种草/剧情 | 手机+节奏感，前3秒钩子 | 日更或隔日更 |
| B站 | 16:9横版 | 3-15分钟 | 深度/教程/测评 | 录屏或相机，内容深度优先 | 周更，系列5-10期 |
| 视频号 | 9:16竖版 | 1-5分钟 | 知识/生活/种草 | 手机+自然光 | 每周2-3期 |
| 知乎 | 16:9横版 | 3-10分钟 | 深度解读/教程 | 录屏+旁白，专业感 | 按需 |
| 微博 | 1:1/16:9 | 15-60秒 | 热点/资讯/种草 | 手机+快速 | 跟热点走 |

**通用合规**：不使用"最"/"第一"等绝对化用语，产品展示需真实效果

## Profile 感知

- 有 Profile：按 platforms 确定目标平台，按 identity 垂类推荐视频类型
- 无 Profile：询问用户目标平台，默认推荐手机拍摄+剪辑方案

## 规则

1. 方案推荐必须考虑用户的技术能力和预算
2. 平台规格必须准确（分辨率/时长限制不能错）
3. 制作流程必须可操作，每步标注工具和预计耗时
4. 不推荐用户无法获取的工具/API
