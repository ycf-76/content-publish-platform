# AI 小说/网文连载创作（novel-writer）

> 一句灵感 → 世界观/人设 → 三级大纲 → 逐章正文。核心是长篇一致性：
> 在 LLM 上下文内维护状态（伏笔/前情/角色状态），每写一章加载相关上下文。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 灵感/题材 | 是 | 一句话创意，或已有设定 |
| 平台 | 否 | 知乎盐选/番茄/起点/小红书图文（默认按 Profile） |
| 书名 | 否 | 缺省由题材拟定 |
| 本次动作 | 否 | 立项/出大纲/写第N章/续写（默认按对话判断） |

## 执行步骤

### 立项阶段
1. **世界观构建**：时代背景/社会结构/核心冲突/独特设定
2. **人物设定**：主角+核心配角（性格/动机/弧光/关系网）
3. **声音设定**：叙事视角/语气/节奏/风格参考

### 大纲阶段
4. **三级大纲**：全书概览 → 卷纲 → 章节细纲（每章300-500字概要）
5. **黄金三章**：前三章详细大纲（决定读者去留，必须在前3章完成钩子+人设+核心冲突展示）

### 写作阶段
6. **逐章写作**：加载相关上下文（前情摘要+角色状态+伏笔清单）→ 写正文
7. **状态更新**：每章写完更新角色状态/伏笔进度/剧情走向
8. **一致性检查**：核对人物称呼/时间线/设定细节是否与前文矛盾

## 平台适配

| 平台 | 形态 | 单篇字数 | 题材偏好 | 节奏要求 | 连载策略 |
|------|------|---------|---------|---------|---------|
| 小红书 | 图文小说 | 800-1500字+配图 | 都市情感/生活治愈/悬疑 | 每300字一钩子 | 结尾留悬念，引导关注 |
| 知乎盐选 | 长文连载 | 3000-5000字/章 | 悬疑/职场/情感 | 前3章决定去留 | 黄金三章+付费墙 |
| 番茄小说 | 纯文字连载 | 2000-3000字/章 | 玄幻/都市/悬疑 | 每章末尾钩子 | 日更4000字+ |
| 起点 | 纯文字连载 | 3000-5000字/章 | 玄幻/仙侠/都市 | 追读率导向 | 日更，签约要求 |
| 抖音 | 图文轮播 | 500-1000字+9图 | 情感/悬疑/职场 | 每页一个反转 | 系列合集 |
| B站 | 视频脚本 | 按视频时长 | 悬疑/历史/科幻 | 每2分钟一钩子 | 系列专栏 |

## 规则

1. 每章正文 2000-4000 字，不超过 6000 字
2. 对话占比 30-50%，避免大段独白/描写
3. 每章至少 1 个转折或悬念
4. 角色语言要有区分度（不同角色说话方式不同）
5. 不抄袭已有作品的核心设定和情节
6. 伏笔必须在 5 章内回收，不挖不填的坑
