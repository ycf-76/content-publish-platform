## 组件盘点：本项目 vs Easel（用户提问「卡片组件是不是很少」）

### Easel 骨架库（references/card-recipes.md）
封面卡 cover / 正文卡 content（A 账本行、B 管线步骤、C 对比表、D 矩阵 Bento）/ 数据卡 data（巨型数字）/ 金句卡 quote / 收尾卡 CTA，共 9 种卡型骨架。
- layout-laws.md 欠填阶梯第 2 条点名的高容量承载：账本行、时间线、管线步骤、对比表、矩阵格。
- 各骨架最小密度线：账本 ≥4 行带副行、管线 ≥4 步、对比 ≥5 行、矩阵 ≥6 格、单数字卡需「kicker+巨数+单位+解读+来源」五层、金句卡允许 ≤60% 但必须补三个锚点。
- 逃生阀：内容真的少 → 换 1:1（1080×1080），别硬撑 3:4。

### 本项目现状
Block 共 7 个（heading/text/list/steps/compare/image/cta），版式 9 种。
对照结论：**已有 2（封面、收尾）、弱化 3（账本/管线/对比）、缺失 4（矩阵、数据卡、金句卡、时间线）**。

### 核心洞察（本轮最重要的一条）
**真正缺的不是版式数量，是块的数据模型。** 本项目 `list.items: list[str]` 只有一个字符串字段；Easel 账本行是「主行(40-44px) + 副行(24-26px muted) + 可选右侧数据/标签」三元组。
量化：CONTENT_H=1162，填满 75% 需 871px，扣掉 kicker 71 + heading 81 后剩 719px 给清单 ——
- 单行 123px/行 → 需要 **6 行** 才达标
- 带副行 ~190px/行 → 只需 **4 行**
这正对上 Easel「≥4 行带副行」的最小密度线。而 LLM 更愿意写 4 条带说明的要点，而不是 6 条光秃短语。所以"弱化"比"缺失"更致命：调 CSS 永远补不回来。

### 建议优先级（未实施，待用户定）

P2 金句卡 quote（需同时给 audit 加"呼吸型骨架"豁免规则）、时间线 timeline

## 附：前端 vite dev server 被 safe-delete 杀掉的固化修复

### 现象
前端"执行不了 / 确认弹窗不出现"曾一度排查为代码 bug，最终根因是 **vite dev server 整个挂了**：WorkBuddy 注入的 `node-safe-delete-shim` 把"单次删 >50 文件"视为批量删除并中断进程；lockfile 变动触发 vite 重优化依赖要清 133 个 `.vite/deps` 缓存 → 被拦截 → vite 启动 abort → `:3001` 无监听。
代码本身没问题：确认卡片渲染已重构到 `AssistantMessageCell.vue`（静态 `import ChatConfirmCard`，直接 `_createBlock`，无 AsyncComponentWrapper），数据链路 `normalizeAgentMeta` 把 `loop_state_path→loopStatePath` / `workflow_status→workflowStatus` 在 3 个 composable 多处赋值，v-if 条件必满足。

### 固化修复（已落地，用户选"加 Node 启动器"）
- 新增 `frontend/scripts/dev-safe.mjs`：在 spawn vite 前设 `process.env.CODEBUDDY_SAFE_DELETE_ENABLED = '0'`（仅当用户未显式设置时），子进程继承该变量 → shim 在子进程加载时禁用。跨平台、不依赖 shell 语法。
- `frontend/package.json` 加 `"dev:safe": "node scripts/dev-safe.mjs"`。
- 验证：`node --check` 通过；`npm run dev:safe -- --version` 正确拉起 vite 8.1.5。

### 用法（防止复发）
- 下次 lockfile 变动 / `npm install` / 清 `.vite` 缓存导致 vite 起不来时，用 `npm run dev:safe`（而不是 `npm run dev`）启动即可。
- 临时单次绕过也可：`CODEBUDDY_SAFE_DELETE_ENABLED=0 node node_modules/vite/bin/vite.js`（Git Bash 下）。
- 注意：沙箱 `dangerouslyDisableSandbox` 对此无效——shim 在 Node 层，不在沙箱层。
